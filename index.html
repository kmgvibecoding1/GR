2Пользователи и роли

Три роли с разным уровнем доступа.

Открытый

Покупатель

Любой посетитель. Просматривает каталог, ищет товары, собирает корзину, отправляет заказ, видит инструкцию по оплате. Без регистрации.

Ввод ID

Партнёр

Всё, что покупатель, плюс партнёрские цены после ввода ID Greenleaf.

Только владелец

Администратор

Товары, цены, логотип, реквизиты, публикация изменений. Вход через аккаунт Claude.

3Функциональные требования

3.1 Шапка и главная

Логотип и название магазина, подпись «Заказ у официального партнёра», кнопка WhatsApp. Под шапкой вводный блок «Закажите продукцию Greenleaf» с процессом в три шага. Логотип (PNG, JPG, SVG, WebP) загружает администратор, до загрузки показывается текстовое название.

3.2 Каталог

Список в формате прайс-листа

Группировка по категориям. Фото (или заглушка с первой буквой), название, артикул, объём, цена, кнопка «В корзину», которая после добавления становится счётчиком.

Закреплённая панель

Поиск по названию, артикулу и описанию, фильтры по категориям, кнопка «Я партнёр». Видна при прокрутке.

Пустые состояния: пустой каталог показывает покупателю ссылку на WhatsApp, администратору кнопку «Добавить товары». Если поиск ничего не нашёл, выводится подсказка проверить написание или сменить категорию.

3.3 Цены покупателя и партнёра

Покупатель
4 500 ₸

Цена по умолчанию. Проверка не нужна, отметки в заказе нет.

Партнёр
3 200 ₸4 500 ₸

Включается кнопкой «Я партнёр» и вводом ID (минимум 4 цифры). В заказе пометка «партнёрские цены» и ID. Администратор сверяет ID перед подтверждением.

Если партнёрской цены у товара нет, партнёр видит цену покупателя. Режим выключается кнопкой «Вернуть цены для покупателя» и сохраняется в сессии браузера.

3.4 Корзина и форма заказа

Закреплённая кнопка корзины внизу экрана показывает количество и сумму. Корзина открывается боковой панелью: можно менять количество, удалять позиции, видеть итог.

3.7Панель администратора

Кнопка «Управление» видна только владельцу. Три раздела.

Товары

Добавление, правка, удаление, очистка каталога. Поля: название, артикул, категория, обе цены, описание, фото (автоуменьшение до 400 px).

Загрузить прайс

Массовая загрузка из Excel или текста. Перед загрузкой показывается число распознанных товаров и строки с ошибками. Можно добавить или заменить каталог.

Логотип и оплата

Логотип, название и подпись, телефон, список банков, имя получателя, текст внизу страницы.

Формат строки прайса

Артикул; Название; Категория; Цена покупателя; Цена партнёра; Описание
08012; Шампунь для волос 500 мл; Уход за волосами; 4500; 3200; 500 мл

Разделитель: точка с запятой или табуляция. Строка заголовков пропускается автоматически.

Публикация. Изменения сначала видит только администратор. Вверху появляется полоса «Есть изменения, которые ещё не видят покупатели» с кнопкой «Опубликовать изменения». Несохранённые правки хранятся в сессии браузера.

7Ограничения и риски

Партнёрские цены видны в коде страницы

Технически грамотный посетитель найдёт их без ID. Поэтому администратор обязательно проверяет ID перед подтверждением. Для полного скрытия нужна серверная часть с авторизацией.

ID партнёра не проверяется автоматически

Нет доступа к базе Greenleaf, проверка ручная.

Оплата не подтверждается автоматически

Администратор сверяет чек в WhatsApp с суммой и номером заказа.

Товарный знак

Логотип Greenleaf только в виде официального файла от компании, в рамках партнёрского соглашения.

Домен

Сейчас сайт по ссылке claude.ai. Для Greenleafstore.kz нужны домен .kz и хостинг. Панель администратора работает только внутри Claude, на внешнем хостинге каталог обновляется заменой файла.

9Критерии готовности

Сайт готов к запуску, когда выполнено всё ниже.

  • Каталог заполнен актуальными товарами и ценами обоих уровней
  • Загружен официальный логотип
  • Указано имя получателя перевода
  • Тестовый заказ доходит в WhatsApp с правильной суммой
  • Тестовый перевод с номером заказа в комментарии проходит на Kaspi и Halyk
